A / CONTINUITY MECHANICS
THE PLAYHEAD
A point on one path

The spider sits at path.dAtY(scrollY + 50vh). Continuity and reversibility are properties of that formula, not of per-scene code.

THE THREAD
Drawn, then dimmed

One SVG path spans the document. Scroll drives stroke-dashoffset; passed thread stays at 25% and a 260px bright window rides with the spider.

ANCHORS
Generated from layout

Every hub, rail, hanger and pad derives from measured element boxes, so a reflow moves the thread with the content instead of breaking it.

NO FLAT TRAVEL
dy ≥ dx × 0.34

The waypoint emitter forces vertical extent proportional to horizontal travel, capped at 300px, so no run can be skipped in one scroll step.

BEAT CLOCKS
Excursion windows

Hub beats run on beat([yIn, yOut]) — the spider's own span — so a story never plays before its actor arrives.

REDUCED MOTION
Static thread

The path draws fully, the spider parks at the hero anchor, the rAF loop never starts and every beat renders resolved.

Lane travel in dim red, excursions to hubs in bright red. Every horizontal run is sloped, which is why the spider is always visibly travelling rather than jumping.

D / GEOMETRY RULES

Five invariants the layout re-solves on every resize. Each exists because violating it produced a specific visible defect.

LANE CONTAINS RIG
laneW and rigScale solve together

Lane is clamp((W−760)/2, 150, 230); scale is (laneW/2 − 18)/95, capped at 0.9. Deriving the lane from the viewport alone let the rig clip off-canvas.

RAILS FROM MEASURED GUTTERS
Never a constant offset

Each attachment is an L: lane → the midpoint of the real gutter above its own row → down into the card's top edge. Wrapped grids get a 64px row gap so that midpoint exists.

TRAVEL COSTS SCROLL
dy ≥ dx × 0.34, cap 300

Enforced inside the waypoint emitter, so no call site can add a flat traverse. Rails terminate mid-page rather than lane-to-lane, keeping dx — and the reserved band — small.

TRACKS FROM CONTENT WIDTH
auto-fit, never fixed counts

Every grid sizes off W − 2×laneW, so the centred column collapses 4-up and 6-up rows instead of crushing them.

THE TIMELINE IS THE DRAGLINE
spineX = badge column centre

The spine sits on the numbered nodes themselves, so the rig rappels straight down the timeline and each node lights as it passes. The stage renders behind content, so the spider passes behind the badges rather than needing a corridor beside them. Below 760 the timeline drops to two columns with the spine back in the lane.

RULES
  • Femur 44, tibia 46, stride 96 — identical to the approved v1 rig.
  • Feet plant in world space during stance; they never slide.
  • The body is the logo chip, redrawn from the source SVG paths.
  • Swing legs drop to 60% opacity and shorten toward the hip by 16%.
  • Heading eases 0.14 per frame, so direction changes never snap.
  • Scale and the moving flag ease at 0.12 per frame alongside heading, so no beat boundary pops the rig's size or snaps its feet between gait and stance.
  • Lane: left from nav to the services web, one crossing, then right to the end. Mobile stays left throughout.

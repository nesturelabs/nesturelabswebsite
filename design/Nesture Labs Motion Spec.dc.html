A / MOTION TOKENS
DRIVER
Scroll progress

Each pinned section maps -rect.top / (height − vh) to 0…1. All state derives from that one number.

EASING
easeOutCubic

Entrances use 1 − (1−t)³; leg swing uses easeInOutQuad; CSS transitions use cubic-bezier(.2,.8,.2,1).

GAIT
Alternating tetrapod

Stride C = 96px of path length per cycle. Group B offset 0.5. Stance 0…0.5, swing 0.5…1.

RIG
2-bone IK, 8 legs

Femur 44, tibia 46, knee sign per side. Body bob ±2.5px at twice step frequency.

BUDGET
2.4ms / frame

One rAF loop, off-screen scenes skipped, SVG attribute writes only — no layout thrash.

REDUCED MOTION
End state, no pins

Pins collapse to 100vh, every scene renders resolved, keyframes disabled.

RULES
  • Feet plant in world space during stance — they never slide against the ground.
  • The body is the logo chip, redrawn from the source SVG paths, never re-illustrated.
  • Swing legs drop to 60% opacity and shorten toward the hip by 16%.
  • Heading eases 0.14 per frame, so direction changes never snap.
